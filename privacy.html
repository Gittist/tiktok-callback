Datenschutzerklärung – podcast-shorts

Stand: 2. November 2026

Was die Anwendung ist

podcast-shorts ist ein privates Werkzeug, das auf dem Rechner seines Betreibers läuft. Es erstellt aus öffentlich verfügbaren Podcast-Folgen kurze Videos und lädt sie auf den eigenen YouTube-Kanal und das eigene TikTok-Konto des Betreibers hoch. Die Anwendung wird nicht an andere Personen angeboten.

Welche Daten verarbeitet werden

  • Über die YouTube Data API: nur das Hochladen von Videos auf den eigenen Kanal und das Bearbeiten von deren Titeln. Es werden keine Daten anderer Nutzer gelesen.
  • Die Zugangs-Tokens von Google und TikTok werden ausschließlich lokal auf dem Rechner des Betreibers gespeichert und an niemanden weitergegeben.
  • Es werden keine personenbezogenen Daten Dritter erhoben, gespeichert, verkauft oder geteilt. Es gibt keine Werbung, kein Tracking und keine Cookies.

Nutzung von Google-Nutzerdaten

Die Nutzung und Weitergabe von Informationen, die über Google-APIs empfangen werden, entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Widerruf

Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden. Lokal gespeicherte Tokens werden dann gelöscht.
